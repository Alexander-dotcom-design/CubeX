# CubeX

## From Your Cube to Its Solution

CubeX is an interactive Rubik's Cube solver designed to make solving more intuitive. Users can recreate their physical cube digitally, validate its configuration, generate a solution, and watch the solving process step by step.

## Features

- Digital cube configuration
- Physical cube state validation
- Automatic solution generation
- Step-by-step solving visualization
- Bird's-eye view for clear cube visualization
- Interactive cube animations
- Easy reset and reconfiguration

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How It Works

1. Configure the digital cube to match your physical cube.
2. Validate the entered configuration.
3. Generate the solution.
4. Watch the cube solve itself step by step.
